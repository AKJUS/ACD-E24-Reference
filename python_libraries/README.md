# Python libraries

These references cover numerical computation, data processing, visualization,
and machine learning. Each folder introduces a library and contains a reference
sheet with syntax and examples for common operations.

## Contents

| Library | Coverage |
| --- | --- |
| [NumPy](numpy/README.md) | Arrays, indexing, vectorized calculations, and linear algebra. |
| [pandas](pandas/README.md) | Labeled tables, data cleaning, grouping, and aggregation. |
| [Matplotlib and Seaborn](matplotlib-seaborn/README.md) | Figures, axes, statistical plots, and visual comparison. |
| [SciPy](scipy/README.md) | Optimization, interpolation, integration, and scientific methods. |
| [scikit-learn](sklearn/README.md) | Data preparation, model fitting, evaluation, and pipelines. |
