# SciPy

SciPy provides numerical methods for scientific computing. This folder covers
optimization, integration, interpolation, linear algebra, statistics, and signal
processing, with examples for selecting and applying a numerical method.

## Contents

- [Reference sheet](scipy_cheat_sheet.md) — Numerical solvers, curve fitting, integration, matrix operations, and statistical functions.

The reference examples illustrate individual operations. Replace placeholder
variables with your data and run the required imports before using a snippet.
