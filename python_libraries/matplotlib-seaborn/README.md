# Matplotlib and Seaborn

Plots make calculations inspectable and comparisons communicable. This folder
covers Matplotlib figures and axes, plot annotations and layout, and Seaborn
methods for exploring distributions and relationships in data.

## Contents

- [Reference sheet](matplotlib-seaborn_cheat_sheet.md) — Plot types, labels, styles, subplots, statistical graphics, and figure export.

The reference examples illustrate individual operations. Replace placeholder
variables with your data and run the required imports before using a snippet.
