# scikit-learn

scikit-learn supports prediction and pattern discovery from data. This folder
covers preparing features, fitting supervised and unsupervised models, and
evaluating their performance on data held apart from training.

## Contents

- [Reference sheet](sklearn_cheat_sheet.md) — Preprocessing, estimators, evaluation, model selection, and pipelines.

The reference examples illustrate individual operations. Replace placeholder
variables with your data and run the required imports before using a snippet.
