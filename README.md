# Advanced Computational Design — Reference

Technical documentation for computational design: configuring a development
environment, managing source files and dependencies, and working with numerical
data and visualizations. The guides combine setup walkthroughs with references
for everyday use.

## Contents

| Folder | Coverage |
| --- | --- |
| [Development tools](dev_tools/README.md) | GitHub account setup, GitHub Desktop, Miniconda, VS Code, pip, Git, and Markdown. |
| [Python libraries](python_libraries/README.md) | Numerical arrays, tabular data, plotting, scientific computing, and machine learning. |

For an initial installation, follow the development tools sequence:
**GitHub Desktop → Miniconda → Visual Studio Code**.
